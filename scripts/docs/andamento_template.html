O que preciso de você

O Supabase está feito. Para enviar o código e ver o mapa, faltam estes dois itens.

1. Supabase · feito

  1. Quatro migrações e mais duas correções aplicadas.
  2. Três funções no ar e segredo da sincronização gravado.
  3. Depois da publicação, apague o token de acesso em supabase.com/dashboard/account/tokens. Ele expira em 7 dias de qualquer forma.

2. Repositório no GitHub

  1. Crie um repositório vazio, sem README, e me envie o endereço.
  2. Crie um token fino só para esse repositório, com Contents e Workflows em leitura e escrita, e coloque no .env como GITHUB_TOKEN. Sem Workflows, o GitHub recusa os arquivos de .github/workflows.
  3. Se preferir não criar o token, você mesmo roda git push: os commits já estão prontos.

3. Chave do Google Maps

  1. No Google Cloud Console, use uma conta pessoal do Gmail: contas institucionais costumam ter restrições e perdem o acesso quando o curso termina.
  2. Ative o Maps SDK for Android e o Maps SDK for iOS e crie uma chave restrita ao pacote br.com.gasprice.gasprice.
  3. O Google exige uma conta de faturamento, com cota gratuita. Crie um alerta de orçamento. Coloque a chave no .env como GOOGLE_MAPS_API_KEY.

Não envie chaves secretas pelo chat. Deixe tudo no arquivo .env, que fica só no seu computador e nunca vai para o GitHub. Os scripts leem o arquivo sem exibir os valores.

Pendências e riscos

  • O app ainda não rodou num celular de verdadeEste computador não tem Android SDK nem Xcode. O APK sai pelo GitHub Actions quando os segredos estiverem configurados.
  • 15% dos postos ativos estão sem coordenadaSão 6.942 de 45.823 no cadastro da ANP. Eles não aparecem no mapa nem recebem estimativa. A solução prevista é geocodificar o endereço pelo Google uma única vez, o que depende da chave do Google Cloud.
  • Os preços da ANP só são atualizados quando você recarrega uma planilhaHoje o banco tem a pesquisa até 30/06/2026. Ainda não existe a carga automática das semanas novas. Sem ela, os preços oficiais envelhecem e ficam com o ponto vermelho.
  • A estimativa erra em média de R$ 0,25 a R$ 0,39Medido nos dados reais. O app mostra o erro médio de cada estimativa e a marca com "≈". Ela serve como referência, não para escolher entre dois postos vizinhos.
  • O leitor do painel precisa de fotos reaisEle foi testado com textos simulados de painéis. Com as primeiras fotos reais, ajusto os padrões de leitura.
  • O aviso com o app fechado depende do FirebaseHoje o aviso chega com o app aberto ou em segundo plano e fica guardado na lista de notificações.
  • E-mails de cadastro têm limite no plano gratuitoO servidor de e-mail padrão do Supabase envia poucas mensagens por hora. Antes de lançar, configure um SMTP próprio.
  • A previsão de preço ainda não entra no appO modelo só será ligado quando errar menos que repetir o preço atual, como mostrou o experimento.
