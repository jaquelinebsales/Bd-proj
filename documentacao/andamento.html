O que preciso de você

Com estes três itens eu aplico o banco, publico as funções, carrego os dados da ANP e envio o código ao GitHub.

1. Projeto no Supabase

  1. Crie um projeto no plano gratuito, na região São Paulo.
  2. Preencha o arquivo .env da pasta do projeto: URL, chave publishable, chave secreta, senha do banco e token de acesso. O README mostra onde achar cada uma.
  3. Deixe a DATABASE_URL vazia: o script descobre o endereço do banco sozinho.
  4. Salve o arquivo e rode python scripts/supabase/verificar_env.py --gerar-cron-secret. Ele cria a senha da sincronização e lista o que ainda falta, sem mostrar valores.

2. Repositório no GitHub

  1. Crie um repositório vazio, sem README, e me envie o endereço.
  2. Crie um token de acesso fino só para esse repositório, com permissão de escrita em Contents, e coloque no .env como GITHUB_TOKEN.
  3. Se preferir não criar o token, você mesmo roda git push: o commit já está pronto.

3. Chave do Google Maps

  1. No Google Cloud Console, ative o Maps SDK for Android e o Maps SDK for iOS.
  2. Crie uma chave restrita ao pacote br.com.gasprice.gasprice.
  3. Coloque no .env como GOOGLE_MAPS_API_KEY. O Google exige uma conta de faturamento, com cota gratuita mensal.

Não envie chaves secretas pelo chat. Deixe tudo no arquivo .env, que fica só no seu computador e nunca vai para o GitHub. Os scripts leem o arquivo sem exibir os valores.

Pendências e riscos

  • O app ainda não rodou num celular de verdadeEste computador não tem Android SDK nem Xcode. O APK sai pelo GitHub Actions quando os segredos estiverem configurados.
  • O leitor do painel precisa de fotos reaisEle foi testado com textos simulados de painéis. Com as primeiras fotos reais, ajusto os padrões de leitura.
  • O aviso com o app fechado depende do FirebaseHoje o aviso chega com o app aberto ou em segundo plano e fica guardado na lista de notificações.
  • E-mails de cadastro têm limite no plano gratuitoO servidor de e-mail padrão do Supabase envia poucas mensagens por hora. Antes de lançar, configure um SMTP próprio.
  • A previsão de preço ainda não entra no appO modelo só será ligado quando errar menos que repetir o preço atual, como mostrou o experimento.
